# Image Merger

Web application for merging multiple images into a single PDF file.

## Features
- Upload multiple images
- Drag and drop support
- Preview images
- Reorder images
- Generate PDF
- Mobile responsive

## Technologies
- Angular
- Angular Material
- jsPDF
- Firebase Hosting

## Live Demo
https://image-merger-pdf-app.web.app

## Development

### Prerequisites
- Node.js
- npm

### Installation
```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/image-merger.git

# Install dependencies
cd image-merger
npm install

# Serve application
npm start
